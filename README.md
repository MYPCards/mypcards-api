# MYP Cards - API

Esse repositório contém toda a informação sobre a API disponibilizada pelo MYP Cards.

A documentação da API está disponível em https://mypcards.github.io/mypcards-api

## Como obter acesso

Alguns endpoints exigem uma chave no header `X-Api-Token`. Para obtê-la, faça a solicitação em https://mypcards.com/acesso-api — não é preciso abrir issue neste repositório. Depois da aprovação, você mesmo gera a chave no seu painel de acesso à API.

Todo projeto que usa a API precisa exibir, de forma visível onde os dados aparecem, que eles vêm do MYP Cards, com link para https://mypcards.com.
